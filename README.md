# 📚 Compilado de Planos de Aula

---

## 1. 🌐 Arquitetura IoT (Internet das Coisas)
**Objetivo:** Compreender a estrutura física e lógica de sistemas conectados.

*   **Camadas:** Percepção (sensores), Rede (conectividade), Processamento (nuvem) e Aplicação (dashboards).
*   **Protocolos:** MQTT (leve), LoRaWAN (longo alcance), Zigbee (automação).
*   **Hardware:** Microcontroladores (ESP32, Arduino) e Atuadores.
*   **Computação de Borda (Edge):** Processamento local para reduzir latência.

---

## 2. 🤖 Prática IoT: Arduino, C++ e Python
**Objetivo:** Implementação de código e integração entre linguagens.

*   **Arduino (C++):** Programação de baixo nível para controle de hardware.
    *   Estrutura: `void setup()` e `void loop()`.
*   **Python:** Utilizado em Gateways (Raspberry Pi) para processar dados do Arduino.
*   **Integração Serial:** Uso da biblioteca `pySerial` em Python para ler dados enviados pelo Arduino via USB.

---

## 3. 🛡️ Sistemas Operacionais: Segurança Cibernética
**Objetivo:** Comparar mecanismos de defesa em diferentes plataformas.

*   **Segurança no Windows:**
    *   Ferramentas: Windows Defender, UAC (controle de usuário) e BitLocker.
    *   Foco: Proteção contra malwares e facilidade de uso.
*   **Segurança no Linux:**
    *   Ferramentas: Permissões POSIX (`chmod`, `chown`), Sudo e SELinux.
    *   Foco: Modelo de privilégios mínimos e transparência do código fonte.

---

## 4. 📋 Engenharia de Requisitos
**Objetivo:** Técnicas de levantamento e documentação de necessidades de software.

*   **Requisitos:**
    *   **Funcionais (RF):** Funcionalidades do sistema (ex: realizar login).
    *   **Não Funcionais (RNF):** Qualidade e restrições (ex: segurança, tempo de resposta).
*   **Elicitação:** Entrevistas, brainstorming e observação.
*   **Documentação:** Prototipagem (Figma/Wireframes), Diagramas UML e Relatórios Técnicos (SRS).

---

## 5. 🐍 Lógica de Programação com Python
**Objetivo:** Dominar os fundamentos da sintaxe e algoritmos.

*   **Entrada/Saída:** `print()` para exibir e `input()` para receber dados.
*   **Tipagem:** Uso de `int()` e `float()` para cálculos numéricos.
*   **Condicionais:** `if`, `elif` e `else` para tomadas de decisão.
*   **Repetição:** `for` (iteração definida) e `while` (iteração condicional).
*   **Módulos:** `import time` para controle de tempo e pausas (`time.sleep()`).
*   **Projetos Sugeridos:** Calculadoras, Jogos de Adivinhação e Menus Interativos.
